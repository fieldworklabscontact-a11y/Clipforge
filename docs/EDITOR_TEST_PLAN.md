# Editor test plan and current coverage

Run `node --test test/editor*.test.js` for implemented frame-based placement, splitting, invalid overlap, source boundaries, schema validation, recovery records, playback clock calculations, CRC32 and ZIP structure/size, caption SRT conversion, package scope/omission rules, queue transitions, persistence validation and sequential job draining. Run `npm run build` for the client build.

Verified in a browser after the editorial rebuild: import a browser-recorded video, add it to V1, drag the right trim handle (72 → 34 frames), play through to the end, rename the project, add a caption, and see all of it persisted (`clips`, `captions`, `name` read back from the API). The package manifest listed `project.json`, `captions.srt`, two source files and `manifest.json`, with the missing source marked `OMITTED`; Stream-to-ZIP completed across 4 files with byte progress and no error. A queued package job reached `DONE` with a 6,316-byte archive, survived a reload, and downloaded. Undo re-enabled after edits and the timeline ruler/clip selection stayed aligned.

Not verified: relinking a missing source with a genuine matching file, the native save-file picker path (tested through the anchor-download fallback), downloads in browsers other than this Chromium build, and touch trimming.

A browser smoke test for the implemented slice should create an account and project, import a browser-recorded video, add it to V1, split it, wait for autosave, reload, verify local media and clips, and play the second segment. Exercise caption add/remove, trim values, undo/redo, missing-media relink, save failures, navigation protection and legacy project reopening as they are extended. Automated coverage for the persistence flows lives in `test/editor-session.test.js` (autosave races, coalesced flushes, failed writes and retry, unavailable recovery storage, HTTP 409 conflicts that are not retried or overwritten, restoring and discarding drafts) and `test/editor-legacy.test.js` (legacy projects keep unrelated fields, caption validation, legacy caption reading). Both suites drive `src/editor/session.js` and `src/editor/legacy.js`, the modules the editor and legacy Studio use, with fake servers whose writes stay pending until the test resolves them. Remaining manual checks: `/app/studio` redirect preserving the project query, the dedicated `/studio` page rendering without the workspace sidebar, and a real browser round trip through the recovery prompt.

The requested full end-to-end workflow—multiple video and audio tracks, title, transition, effects, export and output inspection—cannot pass because those systems do not yet exist. Long footage, resource pressure, cross-browser codecs, frame accuracy and representative performance workloads remain untested.
